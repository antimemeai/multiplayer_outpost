| L2-2 | 10th H9, GPT H9 | High | WebSocket upgrade did not handle `401 clock_skew` retry with `server_now_ms`. | **FIX:** Parse bounded (`<= 16 KiB`) HTTP `401` JSON body on WS upgrade; return `WsConnectError::ClockSkew { server_now_ms }` and auto-retry ONCE in `ControlClient::connect_ws_with_signer` after updating `clock_offset_ms`. |
| L2-3 | GPT H10, Claude H10, Claude M | High | `tls.rs` allowed `alpn_protocol() == None` and did not canonicalize uppercase/`:443` authority; `http.rs` left `hyper` `max_buf_size` at default ~400 KiB and could leak `conn_task` on timeout. | **FIX:** Canonicalize authority (lowercase, strip default `:443`), require `alpn_protocol() == Some(b"http/1.1")`, set `hyper` `max_buf_size(24 KiB)`, and abort `conn_task` via RAII drop guard. |
| L2-4 | Claude H9, GPT C4, Kimi H4 | Critical | `outpost-p2p` inbound/outbound queues bounded only by frame count (up to ~2 GiB in flight) and unbounded `lifecycle_tx`. | **FIX:** Enforce byte-budget semaphores on inbound Control (4 MiB), Causal (16 MiB), Ephemeral (512 KiB), per-peer outbound streams (1 MiB / 8 MiB), and bound `lifecycle_tx` (1024). |
| L2-5 | 10th H4, GPT H4, GLM M3, Claude M | High | Simultaneous P2P dial glare causes mutual `4409 SUPERSEDED` disconnects (newest-wins race). | **FIX:** Implement deterministic glare tie-break on opposite-direction simultaneous connections (smaller `EndpointId` initiator wins; losing connection closed with `4409`; same-direction reconnect still supersedes cleanly). |

| L3-3 | 10th H7, GPT H7, GLM M5, Claude M | High | `trigger_drain` CAS'd `Serving -> Draining` before storing `drain_reason` (async mutex / `try_lock`), dropping `StopLeaveParty` or `WatchdogInodeMismatch`. | **FIX:** Use `std::sync::Mutex<Option<DaemonExitReason>>` and store `drain_reason` atomically BEFORE transitioning `lifecycle` to `Draining`. |
