# Quarantine Manifest

Reference implementations acquired for study live in gitignored `quarantine/`.
Strip nested `.git` directories and filesystem detritus from extracted working
copies. Never ship quarantined code; record exact sources, commits, licenses,
hashes, and restoration commands here.

Directory SHA-256 hashes are computed deterministically over the stripped tree:
`cd quarantine/<name> && LC_ALL=C find . -type f | sort | xargs shasum -a 256 | shasum -a 256`.
